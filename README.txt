## Как получить API-ключ
1. Зарегистрируйтесь на exchangerate-api.com.
2. Скопируйте API-ключ из личного кабинета.
3. Вставьте ключ в main.py (API_KEY = "ваш_ключ").

## Установка и запуск
1. Установите Python 3.7+.
2. Установите зависимости:
   pip install -r requirements.txt
3. Запустите приложение:
   python main.py

## Примеры использования
- Выберите валюты, введите сумму, нажмите "Конвертировать".
- История операций сохраняется в history.json.
